## 3. sink_finder 结果分类

原始结果：`sink-findings.json`（50 条）。

| 类型 | 数量 | 结论 |
|---|---:|---|
| Crypto (md5) | 14 | 支付协议/Geetest 协议要求，非密码哈希；不修改协议 |
| RCE | 16 | 10 条 `$next()` 为中间件管道误报；6 条 `preg_replace` 为固定正则，无可控 `/e` |
| LFI | 7 | 安装器固定路径、`php://input`、Geetest/ServerJiang 固定端点；`ApiHook` URL 由后台商品配置控制（管理员权限） |
| SQLi | 5 | 全部为 `DB::raw('DATE(...)')` / `DB::raw('count(...)')` 静态表达式，无用户拼接 |
| SSRF | 3 | Geetest/Coinbase 固定 API 域名；`ApiHook` 属管理员可配置出站 URL，已在报告中列为可接受风险 |
| FileWrite / RaceCondition | 2 / 2 | 安装器写 `.env`/`install.lock`，已加 `LOCK_EX`；路径固定 |
| XXE | 1 | `Console/Kernel::load()` 为 Artisan 命令加载，误报 |

未发现：用户可控 `eval`/`system`/`unserialize`/动态 `include`、SQL 字符串拼接、可写任意路径、未过滤文件上传执行。

## 6. 未覆盖 / 发布前待办

1. **完整 Agent Teams 动态审计未执行**：需要 Claude Code Agent Teams、Docker 快照和鉴权模拟；当前环境以静态 + 手工 E2E 替代。
2. **外部 SAST 未执行**：Semgrep / Psalm / Progpilot / PHPStan / CodeQL 未安装；`sink_finder` 只做 AST sink 清单，不做完整污点分析。
3. **生产配置**：HTTPS 环境必须设置 `SESSION_SECURE_COOKIE=true`；`APP_KEY` 需在部署时轮换并在轮换后重新执行 `pay:encrypt-secrets`（或先轮换再加密）。
4. **回滚演练**：旧镜像 tag / 数据库快照回滚尚未在预发执行；回滚前执行 `php artisan pay:decrypt-secrets`。
5. **可接受风险**：`ApiHook` 允许管理员配置任意出站 URL（SSRF 面），建议后续加域名白名单；支付协议 MD5 不能单方面替换。
